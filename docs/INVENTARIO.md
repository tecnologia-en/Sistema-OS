# Inventario de testes

Ainda nao existe inventario de maquinas da empresa neste repositorio publico.

Registrar resultados de benchmark sem dados pessoais:
- CPU e RAM por categoria de maquina;
- tipo de armazenamento (HD/SSD);
- periféricos necessarios (sem seriais ou credenciais);
- software essencial e requisitos de drivers;
- resultado de desempenho em 2 GB RAM.

Dados internos detalhados devem permanecer em armazenamento corporativo com acesso restrito.
