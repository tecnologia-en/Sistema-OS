# Enfoque OS 0.2.2 - Teste real de VM e proxima correcao 0.2.3

Data: 16/10/2026. Escopo: ISO Live em VirtualBox, sem instalacao nos computadores de loja.

## Evidencias do teste da ISO 0.2.2

- Release `v0.2.2-piloto` compilado e aprovado pelo GitHub Actions (build #15). ISO local conferida com SHA256SUMS: `4de0ce094c8b6fc6c8561e3552003ccf5b52842480919c3643068496b19ce606`.
- `Enfoque OS - Teste`, 2 CPUs e 2 GB de RAM. Boot Live da ISO 0.2.2 executado em VM sem instalar no HD.
- Desktop XFCE e Enfoque Central apareceram sem alternancia manual do terminal grafico. O processo teve uma tela preta transitoria antes da area de trabalho.
- Barra de tarefas unica visivel no rodape, ocupando a largura inteira, com Chrome e launchers separados. Area de notificacoes, relogio e lista de janelas presentes. O atalho SIGE apareceu com o favicon recuperado do navegador.
- Ajuste ainda necessario: Intranet e outros icones SVG nao renderizaram corretamente, aparecendo placeholder; adicionar suporte de runtime para SVG e fallback PNG autentico.
- `xdg-settings get default-web-browser` retornou `debian-sensible-browser.desktop`, apesar de `google-chrome.desktop` ter associacoes MIME no esqueleto. Portanto **Chrome ainda nao era reconhecido como default XDG na inicializacao 0.2.2**.
- Corrigido interativamente apenas na VM para testar o mecanismo: `xdg-settings set default-web-browser google-chrome.desktop`, depois `xdg-settings get default-web-browser` retornou `google-chrome.desktop`.
- Nao foram realizados logins no SIGE, testes de impressora fiscal real, instalacao no HD, controle remoto administrativo completo ou homologacao de lojas.

## Ajustes para a ISO 0.2.3

- Autostart da sessao XFCE configura Chrome como default por `xdg-settings` e `xdg-mime` para HTTP, HTTPS, HTML, XHTML e PDF e **verifica o resultado**. Uma marca por usuario permite alterar o navegador mais tarde sem sobrescrita recorrente.
- `/etc/xdg/mimeapps.list` agrega padroes globais; `~/.config/mimeapps.list` continua sendo provisionado pelo esqueleto. Alternativas Debian `x-www-browser` e `gnome-www-browser` apontam para Chrome.
- Runtime inclui `librsvg2-common` para que o tema carregue arquivos SVG. Intranet ganha fallback PNG 48 x 48 gerado diretamente do mesmo favicon SVG oficial, preservando a identidade.
- Testes de regressao automatizados para padroes XDG, verificacao do default, respeito a alteracoes futuras, fallback do icone e estrutura do painel.

## Conclusao

A 0.2.2 comprovou boot e barra inferior na VM, com pendencias visuais de SVG e default XDG. Estas pendencias sao tratadas em 0.2.3, que deve ser recompilada e testada novamente. **Ainda nao homologada para producao.**
