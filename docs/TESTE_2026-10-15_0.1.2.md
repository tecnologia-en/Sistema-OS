# Teste do Enfoque OS 0.1.2 - 15/10/2026

## Escopo

ISO Live experimental Debian 13 (Trixie) / XFCE amd64 compilada pelo GitHub Actions. Testes feitos **somente** na VM VirtualBox "Enfoque OS - Teste", em Windows 11, com 2 CPUs, 2048 MB RAM e rede NAT. A VM de desenvolvimento ficou desligada.

- Artefato baixado: `enfoque-os-iso-3 (1).zip` (contendo ISO e `SHA256SUMS`).
- ISO: `enfoque-os-0.1.2-piloto-amd64.iso`.
- Tamanho ISO: **1.237.876.736 bytes**.
- SHA-256 da ISO: `d6063c7b0158b083916278f6bbafc6856e4bb91357c4ee59a5c84aa3f9dffd8d`.
- Extracao: `dist/0.1.2/`. Hash comparado com `SHA256SUMS`, resultado OK.
- Montagem/inicializacao: `scripts/windows/testar-iso.ps1 -StartVM` confirmou hash, recusou montagem com VM ligada e iniciou corretamente apos desligamento ACPI.

## Aprovado na VM

1. Boot manual pela opcao `Live system (amd64)`, login automatico do usuario Live e desktop XFCE em portugues.
2. `cat /etc/enfoque-os-release` confirma `NAME="Enfoque OS"`, `VERSION="0.1.2"`, `CHANNEL="piloto"`.
3. `setxkbmap -query`: `layout: br`, `model: abnt2`. **Aprovado ao iniciar pela ISO.** Para injetar comandos por VirtualBox, o teste alternou temporariamente para teclado US e depois restaurou BR; essa alteracao e apenas da sessao de teste.
4. `locale -a` inclui `pt_BR.utf8`.
5. `timedatectl` identifica `America/Sao_Paulo (-03, -0300)`; menus do XFCE e Firefox em portugues.
6. `enfoque-diagnostico` abre e informa hardware, armazenamento, RAM e interface NAT sem envio externo.
7. Rede: interface `enp0s3` com IP `10.0.2.15/24`; `ping -c 2 debian.org` enviou 2 e recebeu 2 pacotes, 0% de perda.
8. Firefox ESR abriu `https://www.debian.org` com pagina renderizada e conteudo em portugues.
9. `sudo reboot` reiniciou corretamente; apos nova selecao manual do Live, o desktop XFCE voltou normalmente.

## Metricas pontuais

- RAM total reconhecida: **1973 MiB**.
- RAM usada em repouso com diagnostico (sem Firefox): aproximadamente **412 MiB**; disponivel: **1,5 GiB**.
- RAM com Firefox aberto na pagina do Debian: **998 MiB** usada, **974 MiB** disponivel.
- `systemd-analyze`: **22.987 s kernel + 18.085 s userspace = 41.072 s**. Uma medicao, sem benchmark representativo de hardware fisico.

## Riscos e pendencias

- A ISO e modo **Live experimental**, nao possui instalador corporativo validado nem persistencia; nao instalar em PDVs ou PCs das lojas.
- O menu Live ainda exige selecionar a entrada manualmente no VirtualBox.
- A interface utiliza aparencia padrao XFCE/Debian (sem tema e wallpaper proprios).
- O driver `vmwgfx` registra avisos de hypervisor nao suportado sob VMSVGA; o desktop funcionou, mas o aviso nao foi corrigido.
- Em `timedatectl`, `System clock synchronized: no` no momento da medicao; validar sincronizacao NTP no proximo ciclo.
- Sem teste real de SIGE, impressoras, leitores, certificados, perifericos, armazenamento HD, usuarios limitados, instalador, seguranca corporativa, gestao central ou rollback.
- `sudo` sem senha e usuario Live sao aceitaveis **somente** para laboratorio; nao configuracao definitiva.

## Resultado

**0.1.2 aprovada como piloto Live na VM de 2 GB. Nao homologada para producao.**

Fluxo de trabalho: Windows (codigo local) + GitHub (versionamento e compilacao CI) + VM dedicada (validacao). Nenhuma alteracao foi feita nos PCs ou sistemas das lojas.
